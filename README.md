# Resume

This repository contains the source code for Izadora Pivotto Abe's personal portfolio website, showcasing her work in Data Strategy, Business Intelligence, automation, and AI.

> Technologies: 🟨 JavaScript · 🌐 HTML · 🎨 CSS · ✨ Cursor

---

## Start Here

This project is a responsive single-page portfolio designed to present professional experience, education, certifications, selected projects, and technical skills.

The website supports Portuguese and English, adapts to the visitor's system light or dark theme, and allows both language and theme preferences to be changed directly on the page.

---

## Features

| Feature | Description |
| --- | --- |
| Bilingual interface | Portuguese and English content with a language switcher. |
| Theme preference | Uses the operating system's light or dark preference by default. |
| Responsive layout | Designed for desktop and mobile screens. |
| Professional timeline | Highlights experience, education, certifications, projects, and skills. |
